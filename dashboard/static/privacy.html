Privacy Policy

Effective Date: November 1, 2026

1. Overview

This Privacy Policy governs the collection, storage, and processing of technical execution telemetry and workspace data within the Autonomous Agent System. This software runs locally within a secure sandbox environment on the host machine.

2. Data Storage and Local Isolation

All episodic execution histories, planner traces, task observations, and self-learning lessons are persisted strictly in local SQLite databases (episodes.db) located on your local disk. No telemetry, task prompts, or execution traces are transmitted to external commercial aggregators or analytics trackers.

3. Deterministic Sandboxing and File Access

The file system tools operate within a bounded sandbox workspace. Path traversal outside the assigned root is intercepted and denied. AST inspection verifies that untrusted code does not invoke restricted operating system binaries, network sockets, or unauthorized subprocesses.

4. Third-Party Language Model Providers

When configuring an external model provider (such as OpenAI or Google Cloud Vertex AI), prompt inputs and system messages are subject to the respective provider's data processing terms. In offline mock mode, all generation is handled locally without outbound network connections.

5. Data Retention and Erasure

Users maintain full ownership and control of local data. To erase all stored memory traces, delete the local episodes.db file or run the clean target from the Makefile.

6. Contact and Inquiries

For security inquiries, audit verifications, or documentation requests, consult the project security documentation located at docs/safety.md.
